CR Dynamic Background

Sistema de background animado com Ken Burns, partículas CSS e overlay dinâmico. 100% CSS, sem JavaScript.

Como Usar

Copie o bloco HTML do background e o CSS correspondente para seu projeto. Troque a imagem de fundo alterando a propriedade background-image em .cr-bg-layer.

Sistema de Temas

Adicione a classe theme-section e uma variante de cor (ex: theme-turquesa) para aplicar filtros hue-rotate不同的背景。

Personalização

Imagem: Altere a URL em .cr-bg-layer
Velocidade Ken Burns: Ajuste animation: crKenBurns 30s
Intensidade do Overlay: Modifique as cores/alpha no linear-gradient
Partículas: Adicione/remova divs .cr-particle e ajuste suas propriedades
