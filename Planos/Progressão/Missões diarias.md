🎯 Estrutura das Missões Diárias
O usuário recebe 3 missões aleatórias por dia.

Cada missão concede uma quantidade de XP proporcional à dificuldade.

Ao completar as 3 missões, o usuário recebe um bônus extra de XP (ex.: +50 XP).

Missões não dependem de dias anteriores (evitamos streaks como “treinar X dias seguidos”).

Missões premium exclusivas foram removidas — todos podem participar.

Missões de datas comemorativas foram substituídas por treinos caseiros (já que academias podem estar fechadas).

Missões avançadas são dinâmicas, envolvendo exercícios das fichas do próprio usuário.

🔑 Insights

Final de semana mantém XP dobrado nos treinos, mas não como missão específica.

Avançadas dinâmicas garantem que cada usuário tenha desafios ligados às suas próprias fichas.
